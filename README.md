# Прототип страницы «О клинике» — beloostrov.groupmmc.ru/about/

Одностраничный HTML-прототип новой структуры: hero → о клинике → технологии → эксперты → комплекс → запись.

## Как открыть

Локальный сервер (file:// браузеры блокируют шрифты и часть ассетов):

```
python -m http.server 8765 --bind 127.0.0.1
```

Затем: `http://127.0.0.1:8765/about-page/index.html`

Шрифты лежат локально (`assets/fonts`), интернет не нужен.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: разметка, стили, скрипт фильтра, JSON-LD |
| `assets/img/hero-about.webp` | Hero-фото с текущей страницы `/about/` |
| `assets/img/logo.svg` | Логотип ММЦ · Белоостров с сайта |
| `assets/experts/*.jpg` | 15 портретов экспертов с сайта (для прототипа) |

## Структура страницы (продающая)

1. **Hero** — обещание (сложные операции и рак), четыре доказательства, две кнопки.
2. **Четыре повода** — онкология, кардиохирургия, нейрохирургия, травматология.
3. **Почему здесь** — три аргумента с доказательствами.
4. **Технологии** — шесть карточек с результатом для пациента.
5. **CTA-вставка** — «Не знаете, с чего начать».
6. **Эксперты** — три профиля с портретами, статистика 25/7/11/2, лента всех 25.
7. **Пять шагов** — путь пациента от звонка до восстановления.
8. **Случаи** — три клинических случая со ссылками.
9. **Условия** — оплата, документы, дорога.
10. **FAQ** — пять возражений.
11. **Контактная полоса** — на всю ширину, переходит в футер.

## Дизайн-токены

Взяты с действующего сайта, чтобы прототип не выглядел «чужим»:

- Шрифт: Montserrat 300/400/700 (локальные woff2 с сайта).
- Цвета: `#15396B` (navy), `#0089FA` (blue), `#F5F8FC` (фон секций), `#E4EBF4` (линии).
- Контейнер: 1190 px, поля 20 px.
- Форма фото эксперта: `border-radius: 88px 0` — та же логика скругления, что у карточек врачей на сайте.
